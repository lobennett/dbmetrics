# Validation

1. Define the quantity, units and sampling limits.
2. Inspect a video and its calculation in a notebook.
3. Compare contrasting examples and failures with manual judgments.
4. Freeze the method; evaluate a separate review set against predetermined criteria.
5. Record versions, thresholds, coverage and tests before website integration.

For classifications, report sensitivity, specificity and uncertainty, not accuracy alone.
Failed or unmeasured values are never negatives. Passing code tests establishes
implementation behavior, not classification accuracy.

Half-video similarity, continuity diagnostics and affect helpers remain experimental.
Installing this package does not change the website or running cluster jobs.
